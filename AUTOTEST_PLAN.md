# План автотестирования SVG to DXF Converter

## Обзор
Автотестирование предназначено для проверки всех аспектов работы приложения как для пользователя (через F12), так и для ИИ (программно).

## Архитектура тестирования

### Два режима активации:
1. **Пользовательский:** F12 → кнопка "Создать отчет"
2. **ИИ режим:** программная активация → автоматическое сохранение логов

### Локации логов:
- **Пользователь:** `~/svg-to-dxf-converter/logs/`
- **ИИ:** `./autotest_logs/`

## Тестовые сценарии

### 1. Тестирование UI элементов
- **Проверка кнопок:**
  - Наличие кнопок selectFilesBtn, selectFolderBtn, convertBtn
  - Обработчики событий привязаны
  - Визуальная доступность (не disabled)
  - CSS стили применены корректно

- **Проверка диалогов:**
  - Открытие диалога файлов
  - Открытие диалога папок  
  - Навигация по файловой системе
  - Кнопки "Отмена", "Выбрать", "Наверх"
  - Фильтрация SVG файлов

- **Проверка области файлов:**
  - Отображение списка выбранных файлов
  - Обновление статусов файлов
  - Прокрутка при большом количестве файлов

### 2. Тестирование файловой системы
- **Доступность директорий:**
  - Чтение домашней директории
  - Чтение системных папок
  - Проверка прав доступа

- **Операции с файлами:**
  - Поиск SVG файлов
  - Чтение метаданных файлов
  - Проверка существования файлов

- **Кросс-платформенность:**
  - Windows пути (C:\, D:\)
  - Unix пути (/home, /usr)
  - Разделители путей

### 3. Тестирование конвертации
- **Базовая конвертация:**
  - SVG → DXF преобразование
  - Проверка валидности выходного файла
  - Сохранение рядом с исходным

- **Обработка ошибок:**
  - Невалидные SVG файлы
  - Пустые файлы
  - Отсутствующие файлы

- **Специальные случаи:**
  - Папки только для чтения
  - Альтернативные пути сохранения
  - Конфликт имен файлов

### 4. Тестирование производительности
- **Время загрузки UI**
- **Время открытия диалогов**
- **Скорость конвертации**
- **Использование памяти**

### 5. Тестирование доступности
- **Навигация клавиатурой**
- **Читаемость текста**
- **Контрастность цветов**
- **Размеры интерактивных элементов**

## Автоматические тесты

### Функция запуска (ИИ режим):
```javascript
run_autotest() {
    // 1. Активация дебаг режима
    // 2. Последовательное выполнение тестов
    // 3. Сбор результатов
    // 4. Сохранение отчета
}
```

### Тестовые функции:
- `test_ui_elements()` - проверка UI
- `test_file_system()` - проверка файловой системы  
- `test_conversion()` - проверка конвертации
- `test_performance()` - проверка производительности
- `test_accessibility()` - проверка доступности

## Расписание тестирования

### При запуске приложения:
- Базовая проверка UI элементов
- Проверка доступности файловой системы

### В дебаг режиме:
- Полный набор тестов
- Детальное логирование
- Сбор метрик производительности

### По требованию ИИ:
- Полное автотестирование
- Автоматическое сохранение отчета
- Интеграция с CI/CD

## Критерии успеха

### Уровень готовности:
- **Critical:** 100% тестов пройдено
- **High:** 90%+ тестов пройдено  
- **Medium:** 75%+ тестов пройдено
- **Low:** <75% тестов пройдено

### Блокирующие проблемы:
- Отсутствие конвертации SVG→DXF
- Недоступность файловой системы
- Не работают UI элементы
