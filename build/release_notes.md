# 🐱 SVG to DXF Converter — v1.0.0

Кроссплатформенный конвертер **SVG → DXF** на Rust + Yew + Tauri 2.0.  
В этом релизе — все последние улучшения UX и **новая портативная версия для Windows** 💾

---

## ✨ Что нового

- 🔔 **Анимация-подсказка** кнопки «Конвертировать» — пока не выбраны SVG и папка вывода, кнопка пульсирует и показывает 👉 точное действие.
- 💾 **Сохранение папок между запусками** — выходная папка и последняя папка выбора SVG запоминаются (рядом с `.exe` в portable-режиме или в конфиге приложения).
- 📊 **Прогресс-бар конвертации** — полоса с текстом «N / M (XX%)», видимая только во время работы.
- 🔁 **Чекбокс «Заменять файлы»** рядом с кнопкой: выключен → имена с индексом `_1`, `_2`…; включен → перезапись.
- 🏷️ **Суффиксы имён** `+ _color` / `+ _hatch` — активны при включённых «Сохранять цвета» / «Заливка линиями».
- 🪟 **Windows собирается из Linux** (cross-compile через MinGW + NSIS), консольное окно убрано (`windows_subsystem`).

## 💿 Портативная версия (Windows)

Просто распакуйте zip и запустите `svg2dxf-tauri-app.exe` — ничего не устанавливается, можно переносить на флешке. Настройки папок сохраняются рядом с exe.

## ⚠️ Про SmartScreen

Установщик и портативная версия **не подписаны** цифровым сертификатом (подпись ставится только на Windows-хосте). При первом запуске Windows SmartScreen может показать предупреждение — нажмите **«Подробнее → Всё равно запустить»**. Это не баг, а отсутствие платного Authenticode-сертификата.

Требования: Windows 10+ с **WebView2 Runtime** (обычно уже в системе).

---

## 🔧 Возможности конвертации

Цвета (ACI + true-color), заливка линиями (hatch-by-lines), текст → MTEXT, встроенные растры (PNG/JPEG/GIF → вектор через marching squares), массовая конвертация, Drag & Drop.

Открывать результат: **LibreCAD** (DXF), **Gwenview** (SVG).
