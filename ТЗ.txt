Техническое задание на разработку программы для конвертации SVG файлов в DXF файлы.

Программа должна быть кросс-платформенной и работать на Windows, Linux и macOS.
Программа должна быть написана на Rust.

    Необходим UI интерфейс.
    В интерфейсе должна быть кнопка выбора конкретных файлов SVG для конвертации.
    В интерфейсе должна быть кнопка выбора папки с файлами SVG для конвертации.
    Выбираться должны через диалоговое окно с навигацией по файловой системе.
    После выбора файлов они должна отображаться в списке выбранных файлов в окне программы.
    В списке должны отображаться статус файлов меняющийся в зависимости от стадии работы программы.
    Статус после добавления (добавлен), статус в процессе конвертации (конвертация) и статус после ее завершения (завершено).
    Статусы должны быть анимированы, показаны иконками с подсказками при наведении.
    Для начала конвертации должна быть еще одна кнопка.
    Конвертированные файлы должны расположиться в папке рядом с исходными.
    Если исходная папка доступна только для чтения, то сохранить надо в папку на выбор пользоваля, показав окно ее выбора.
    Папка выбранная должна использоваться только для файлов которые не удалось сохранить в исходную.
    Дизайн должен быть с закругленными краями, лаконичным и эргономичным, современным.
    Должна быть кнопка справки с информацией о том какие есть возможности и ограничения по конвертации. И краткое пояснения интерфейса.

Программа должна иметь дебаг режим и возможность автотестирования с созданием логов. Папку для логов нужно создавать в домашней директории пользователя. Эту директорию в режиме дебага можно менять через выбор в диалоговом окне.
Автотестирование должно затрагивать работу кнопок, вызова диалоговых окон, проверка навигации, доступности файловой системы, проверку аспектов интерфейса, конвертацию файлов. 
Войти в режим дебага должна быть возможность по клавише F12 или программно, через флаг.
Автотестирование должно быть доступно для использования моделью ИИ при разработке.
Должен быть разработан план автотестирования.

Проект должен содержать скомпилированные версии для всех платформ в папке releases. 
В проекте содержится файл CHANGELOG.md с описанием изменений в проекте, который должен поддерживаться во время разработки.
