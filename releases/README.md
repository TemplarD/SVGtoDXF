# SVG to DXF Converter v1.0.0 - Релизные пакеты

## 📦 Доступные пакеты

### 🐧 Linux
- **SVG to DXF_1.0.0_amd64.deb** (4.8MB) - Для Debian/Ubuntu и совместимых дистрибутивов
- **SVG to DXF_1.0.0_amd64.AppImage** (75MB) - Универсальный формат для всех Linux дистрибутивов

### 🪟 Windows
- **SVG to DXF_1.0.0_x64-setup.exe** (5.5MB) - Установщик для Windows x64
- **app.exe** - Исполняемый файл для Windows (без установки)

### 🍎 macOS
- *В разработке* - Требуется macOS среда для сборки

## 🚀 Инструкция по установке

### Linux (DEB)
```bash
sudo dpkg -i "SVG to DXF_1.0.0_amd64.deb"
sudo apt-get install -f  # Если нужны зависимости
```

### Linux (AppImage)
```bash
chmod +x "SVG to DXF_1.0.0_amd64.AppImage"
./"SVG to DXF_1.0.0_amd64.AppImage"
```

### Windows
1. Скачайте `SVG to DXF_1.0.0_x64-setup.exe`
2. Запустите установщик
3. Следуйте инструкциям

## ✅ Функциональность

- ✅ Конвертация SVG в DXF
- ✅ Пакетная обработка файлов
- ✅ Современный UI интерфейс
- ✅ Система логирования
- ✅ Автотестирование (Ctrl+F12)
- ✅ Кроссплатформенность

## 🔧 Системные требования

- **Linux**: GTK 3, libwebkit2gtk-4.0
- **Windows**: Windows 10/11 x64
- **macOS**: macOS 10.13+ (в разработке)
